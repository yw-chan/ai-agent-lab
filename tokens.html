看完要記得

    
    
      
  • API 是無狀態的：每一輪都把 system、工具定義、整段歷史重送一次，所以第 N 輪的輸入包含前面所有內容。

  • 工具結果（例如讀進來的整個檔案）會留在歷史裡，之後每一輪都要再付一次。
    • 
      
  • 思考 token 看不到全文，但按輸出價計費；輸出單價通常是輸入的好幾倍。
    • 
      
  • 工具和 MCP 越多，固定成本越高：沒用到的工具也在每一輪的輸入裡。

口試怎麼答（約 30 秒）
一次請求的 token 分成輸入和輸出兩邊。輸入是每次都整包重送的內容，包含 system prompt、工具定義、對話歷史和這一輪的訊息。輸出是模型這次產生的東西，包含看不到全文的思考，也包含它要呼叫工具的那段文字。API 不會記得上一輪，所以對話越長，每一輪就越貴。
  • 被追問時可以補：輸出單價通常是輸入的好幾倍，思考 token 也按輸出價算。
  • 工具讀進來的大檔案會留在歷史裡，之後每一輪都要再付一次。
  • 計費通常分成四種：沒命中快取的輸入、寫入快取、讀取快取和輸出。
