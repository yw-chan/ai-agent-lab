Agent 實驗室

每一頁都是同一種玩法：左邊改你要送出的內容，右邊看到真正送給模型的 request、模型回傳的 response，還有 token、費用、上下文裡到底裝了什麼。題號對應課程版 11 題和面試版 16 題。

你的輸入→Agent 組 request→遠端模型→tool_use→本機執行→tool_result→回答

模型基礎

一次 API 呼叫裡發生了什麼：送了哪些 token、花多少錢、哪些可以重用。

課程 1面試 1

Token 組成

調整 system、工具、歷史、附件、思考，看 request JSON 和每一塊佔多少 token；連續送出看每輪越來越貴。
課程 2面試 2

Reasoning Effort

換任務難度和推理強度，比較思考 token、延遲、費用和答對機率，看什麼時候值得調高。
課程 3面試 3

Prompt Cache

連續送出請求，看前綴從哪裡開始對不上、快取為什麼失效，以及 usage 裡的讀取和寫入。
課程 4面試 4、5

Context Window

往上下文裡塞東西，看 1M 視窗怎麼被填滿、每輪費用和品質怎麼變、壓縮時什麼會不見。

Agent 機制

Agent 怎麼用工具、怎麼記事情、怎麼分工。

課程 5面試 6

Tool、MCP、Skill

一步一步看遠端模型怎麼「要求」呼叫工具、你電腦上的 Agent 怎麼執行，MCP 和 Skill 什麼時候載入。
課程 6面試 7、8

長任務記憶

把規則放在聊天、CLAUDE.md、rules 或 hook，跑一段長任務再壓縮，看哪些規則還在；Claude Code 的記憶從哪裡來。
課程 7面試 9

Subagent

主對話自己做和派子代理比一比：上下文、費用、時間，交辦內容少寫一項會出什麼問題。
課程 8面試 10

模型路由

替長任務的每個階段選模型，比較頂規一路到底、全部小型和分工，加上連錯兩次升級的規則。

工程實踐

把 AI 放進開發流程：拆任務、審程式、驗測試、提交。

課程 9面試 11

需求拆解

輸入一個業務需求，看垂直切片和水平分層的差別，以及每個工作項目的交辦 prompt。
課程 10面試 12

Code Review Skill

對一段有問題的 C# diff 執行審查，選檢查維度、開關對抗性驗證，看報告和 SKILL.md 長什麼樣。
課程 11面試 13

測試有效性

覆蓋率很高但變異測試分數很低：找出沒斷言、假陽性、flaky 和過度耦合的測試。
面試 14、15、16

開發習慣

commit 產生器和檢查，加上一套固定的開發流程，每一步對應 Claude Code 的做法。

所有 token、費用、延遲都是教學用的估算，不是真實的 tokenizer 或價目表；API 欄位以官方文件為準。
