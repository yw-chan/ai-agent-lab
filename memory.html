看完要記得

  • 規則寫進檔案（CLAUDE.md、.claude/rules），不要只在聊天裡說：聊天會被壓縮，檔案會重新載入。
  • 真正不能違反的，用 hooks／測試強制：hook 不靠模型記得，直接擋下。
  • 任務切小：一個 session 做一件事，做完就開新的，不要讓上下文一路膨脹。
  • 進度寫成檔案（例如 PROGRESS.md）：換 session 或壓縮之後，新的 Agent 讀檔就能接手。
  • 交辦子代理要寫清楚：子代理不會繼承主對話的聊天內容，只有 brief 裡寫的才可靠。
